# 全局变形演示

## 启动

使用 Unity 2022.3.62f3c1 打开本工程，从菜单选择 **Tools > Global Deformation > Open Demo Scene**，然后点击 Play。

也可直接打开 `Assets/Scenes/GlobalDeformationScene.unity`。原 OBJ 浏览器中的“全局变形 / FFD”和参数曲线界面的“DEFORM / FFD”按钮也可进入此场景。

启动后默认加载 `Assets/StreamingAssets/DeformationSample.obj`，它是带细分的椭圆截面柱体，便于观察弯曲和扭曲。

## 导入 OBJ

- 编辑器 Play 模式下点击“选择 OBJ”，选择磁盘上的 `.obj` 文件。
- 也可在路径框粘贴绝对路径，点击“导入路径”。支持中文和包含空格的路径，允许路径外层带双引号。
- `Assets/...` 路径相对工程目录；其他相对路径从 `StreamingAssets` 解析。打包后可使用磁盘绝对路径导入外部文件。
- 无效文件会显示错误，保留当前模型。点击“示例模型”返回内置示例。
- 复用工程原有 OBJ 解析器，支持位置、UV、法线、负索引和面三角化；不加载 MTL 材质/贴图。复杂凹多边形建议导出时先三角化。

模型显示前会根据包围框居中并等比缩放，使最长边为 4 个演示单位。原始 OBJ 顶点仍保存在 `ObjLoadedModel.SourceVertices`，不回写源文件。

## 锥化、扭曲、弯曲

1. 点击“锥化 Taper”“扭曲 Twist”或“弯曲 Bend”。
2. 选择模型局部 X、Y 或 Z 轴。
3. 拖动强度滑块，实时观察模型。
4. 点击“复位全部”恢复原状。

锥化以包围框底端为固定端，顶端横截面按 `1 + 系数` 缩放。扭曲角度随轴向高度线性增加，滑块表示顶端总角度。弯曲将轴向中心线映射为圆弧，以底端为基准，滑块表示总弯曲角度。弯曲平面随轴确定：Y 轴在 XY 平面，X 轴在 XZ 平面，Z 轴在 YZ 平面。

每种变形都直接读取原始顶点，互不叠加；切换模式会将强度归零。FFD 控制点的编辑状态会保留，直到复位、重新导入或重建网格。

**建议演示参数：** 默认 Y 轴；锥化系数 −0.8，扭曲 210°，弯曲 110°。细分不足的模型只能移动已有顶点，弯曲会显得折线化；只有底面顶点和轴心顶点的金字塔，沿其高度锥化可能没有可见变化。这是网格拓扑的限制，可使用内置细分示例观察。

## FFD：从初始网格到终止网格

1. 点击“FFD 自由变形”。
2. 输入每轴点数 `n`（2–6），点击“重建”。此时由模型原始包围框得到规则的 `n×n×n` 控制点，模型保持初始形状。注意 n 是点数，每轴分段数为 n−1。
3. 左键点击青色控制点，黄色表示当前选中点；按住左键拖动，模型实时变化。
4. 需要精确选择时，输入从 0 开始的 `i / j / k` 索引，点击“选择点”。
5. 输入该点的局部 `X / Y / Z` 坐标，点击“应用坐标”。坐标使用居中且等比缩放后的演示空间，数值输入小数点使用英文句点。
6. “复位此点”恢复该控制点；“复位全部”恢复全部控制点和模型。

拖动平面平行于屏幕。右键转动视角后再拖动，可以沿不同空间方向编辑；精确三维编辑可直接输入坐标。重叠或被模型遮挡的点可通过索引选中。重建 n 会丢弃此前网格位移，重新得到规则网格。

例如 n=3 时共有 27 个控制点，选择 `(2,2,2)`，将其 X 坐标增加 1，点击“应用坐标”，观察对应角落的平滑变形。继续移动其余顶层点可以把上端整体推向一侧。

## 视角操作

右键旋转，中键平移，滚轮缩放；“聚焦模型”使当前变形结果重新居中。控制区与模型视图区分开，操作界面时不会旋转视角。

## 实现结构

- `DeformationMath.cs`：锥化、扭曲和圆弧弯曲映射，以及三个局部轴的坐标变换。
- `FfdLattice.cs`：包围框规则网格、Bernstein 基函数缓存和三维张量积插值，阶数为 n−1。扁平模型会对零厚度方向添加微小厚度，避免除零。
- `GlobalDeformationController.cs`：运行时 OBJ 导入、原始与渲染顶点映射、网格更新、控制点拾取与拖动、模式选择和资源释放。
- `DeformationUI.cs`：运行时 UGUI 面板。
- `Editor/GlobalDeformationSceneMenu.cs`：创建、打开场景并登记到 Build Settings。
- `Editor/GlobalDeformationValidation.cs`：数学性质及 Play 模式导入/模式/参数/复位/FFD/UI 事件冒烟验证，菜单 **Tools > Global Deformation > Run Validation (enters Play Mode)**。报告默认写入 `Temp/GlobalDeformationValidation`。

FFD 参数始终依据原始包围框计算。对每个原始顶点预缓存三个方向的一维基函数，编辑后计算变形位置，再通过原有映射更新全部渲染顶点，保证 UV/法线拆分出的顶点位置一致。变形后重新计算包围框和法线，存在 UV 时重新计算切线。原有硬边和 UV 接缝仍沿用 OBJ 的顶点拆分结构。

CPU FFD 的更新量约为“原始顶点数 × n³”，只在编辑控制点或参数时更新。大模型建议先使用 n=2 或 n=3；n=6 为 216 个控制点。程序不会自动细分导入网格。
